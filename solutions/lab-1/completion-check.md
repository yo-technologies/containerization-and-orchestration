# Проверка комплекта ЛР1

Дата завершения: 26 октября 2026 года. Части 1–8 выполнены, проверки понимания пройдены. Финальный выбор студента — память относительно лимита, доля CPU throttling и новые OOM kills; [обоснование](monitoring/alerts.md) включено в основной отчёт.

## Наличие материалов

- [Основной отчёт](README.md): язык сервиса Go; namespace/cgroup/privilege опыты; сравнение mydocker/Docker/gVisor; сборки, cache и volume; мониторинг и выбранные метрики.
- API: api/main.go, api/go.mod, api/main_test.go; api/Dockerfile и api/Dockerfile.single.
- Запускатель: mydocker.sh; seccomp/deny-getppid.json, загрузчик и probe.
- Мониторинг: monitoring/cgroup-exporter.py, prometheus-lima-values.yaml, lab1-resources.json, load-90s.sh и руководства.
- В evidence/ сохранены 37 оригинальных PNG и протоколы экспериментов, включая все виды снимков, перечисленные в задании.

## Проверка целостности

Проверены локальные Markdown-ссылки и ссылки на заголовки: ошибок нет. Все 37 PNG проверены по сигнатуре, структуре chunks, CRC и завершающему IEND; ошибок нет. [SHA256SUMS](evidence/SHA256SUMS) содержит контрольные суммы полного набора изображений. Для проверки из evidence/ можно выполнить shasum -a 256 -c SHA256SUMS.

Рабочие материалы outputs/labs/ синхронизированы с solutions/ основного репозитория; игнорируемые bin/ исключены из сравнения, ранее собранные бинарники не удалялись. kubeconfig остаётся в work/observability и не включён в solutions/.

Код API при завершении не изменялся, его тесты повторно не запускались: прежняя верификация сохранена в verification.md. Для добавленного exporter отдельно проверены единицы, counters, limits и обработка отсутствующих файлов; для нагрузочного скрипта bash -n, для Helm — рендеринг и затем фактические развёртывания студентом. Работа Grafana проверена по реальным screenshots и Prometheus API.

## Состояние после опытов

API mydocker в Lima штатно остановлен сценарием нагрузки, его cgroup пуста. Exporter и локальный observability-стек не выключались. Другие учебные Docker-контейнеры и VM здесь не удалялись. Стек ЛР2 развёрнут для переиспользования, но полная собственная проверка прикладных сценариев ЛР2 не заявляется.
