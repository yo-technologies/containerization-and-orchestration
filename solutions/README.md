# Отчёты по контейнеризации и наблюдаемости

| Работа | Отчёт | Что проверено |
| --- | --- | --- |
| ЛР1. Свой Docker | [Открыть отчёт](lab-1/README.md) | Все восемь частей: namespaces, cgroups, права, свой запускатель, Docker, образы, gVisor и ресурсный dashboard; 37 исходных снимков |
| ЛР2. Наблюдаемость API | [Открыть командный отчёт](../lecture-2-observability/README.md) | Метрики, логи, трейсы, три алерта и receiver по командному прохождению; повторное развёртывание 26 октября описано отдельно |

В отчётах приведены результаты и выводы. Подробные команды, промежуточные проверки и служебные протоколы ЛР1 оставлены в её подкаталогах, чтобы не превращать основной текст в журнал всех запусков.

Первую лабораторную выполняли на macOS ARM64, в Lima и Docker Desktop. Для мониторинга подняли командный Helm-стек ЛР2 в kind и добавили exporter cgroup Lima. Новые лабораторные автоматически не начинались.

Основной код мониторинга находится в `lecture-2-observability/` корня репозитория. В `solutions/lab-2/` сохранена отдельная ранняя подготовка вспомогательного API; она не подменяет командный отчёт.

Для сдачи используем прямые ссылки на основной README каждой лабораторной в ветке main.
