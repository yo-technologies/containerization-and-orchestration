# ЛР2: где находится командный отчёт

[Основной отчёт по наблюдаемости API](../../lecture-2-observability/README.md) находится рядом с фактическими Helm values, API, dashboard и скриншотами сокомандника.

В нём описаны RED-метрики, доставка логов Alloy → Loki, трейсы OpenTelemetry → Jaeger, связь по trace_id, три правила Prometheus и доставка уведомлений через Alertmanager. Снимки относятся к командному прохождению 11 октября; повторное развёртывание стека 26 октября указано отдельно.

Эта папка содержит раннюю подготовку другого вспомогательного API: [исходники](api/main.go), [проверки кода](verification.md). Их не следует принимать за отчёт о командных инфраструктурных опытах.

Для первой лабы повторно использован уже готовый стек; её [ресурсный dashboard](../lab-1/monitoring/dashboard.md) и exporter Lima описаны отдельно.
