# Фоновая нагрузка batch

Вспомогательный сервис для ЛР4. Удерживает заданный объём памяти и непрерывно нагружает CPU до SIGTERM/SIGINT. Память затрагивается постранично при старте и каждую секунду; дополнительно память занимает сам Go-процесс.

| Переменная | По умолчанию | Значение |
| --- | ---: | --- |
| `MEMORY_MIB` | 32 | Удерживаемый буфер в MiB, 0–4096 |
| `CPU_WORKERS` | 1 | Число goroutine с CPU-нагрузкой, 0–64; 0 оставляет только память |

Эти параметры управляют нагрузкой приложения. Kubernetes requests и limits задаются отдельно в chart.

Образ собирается командой `docker --context desktop-linux build -t ghcr.io/itmo-labs/shop:batch-0.1.0 .` из этого каталога. Имя образа соответствует allowlist политик ЛР3; сборка не публикует его в registry. Запускать нагрузку будем через chart после настройки ресурсов.
